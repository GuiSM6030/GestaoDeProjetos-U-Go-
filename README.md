# GestaoDeProjetos-U-Go-
Projeto de inovação em mobilidade focado no transporte coletivo sob demanda. A plataforma usa roteirização dinâmica e dados em tempo real para otimizar frotas, oferecendo viagens previsíveis e confortáveis. O objetivo é aliar tecnologia e eficiência logística para modernizar o trânsito urbano.
